# Appendix D: Limitations and Risks

- The dataset is synthetic and researcher-generated.
- No external validation dataset is present.
- MerchantRisk and CardRisk are proxy indicators requiring leakage-risk caution.
- The split is static and offline.
- Confidence intervals, bootstrap estimates, repeated-seed experiments, and formal significance tests are not present.
- Impurity-based feature importance is model-specific and should not be interpreted causally.
